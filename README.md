Aplicación Web Mobile desarrollada en DataFlex 25.0 conectada a MySQL para la administración integral de ligas, equipos, entrenadores, jugadores y posiciones tácticas.Explorar Estructura • Modelo de Datos • Vistas y UI • Instalación • Gitflow📋 Descripción del ProyectoFutbolWebApp es una solución web adaptativa (responsive) diseñada bajo la arquitectura Web Mobile (Drilldown) de DataFlex. El propósito del proyecto (enmarcado en el Sprint 1) es migrar e integrar una base de datos relacional en MySQL con el entorno de DataFlex, reemplazando las tablas embebidas por defecto y proporcionando una interfaz táctil e intuitiva basada en vistas de selección (Select), vistas de detalle/edición (Zoom) y un panel de control centralizado (Dashboard).✨ Características PrincipalesNavegación Drilldown (Mobile-First): Flujo ágil entre listados maestros y formularios de detalle mediante eventos OnRowClick y rutas registradas (WebRegisterPath).Integración ODBC con MySQL: Mapeo completo de tablas relacionales y migración de tablas del sistema de sesiones y usuarios (WebAppUser, WebAppSession, WebAppServerProps).Integridad Referencial (DDOs): Uso de DataDictionaries interconectados para garantizar las reglas de negocio entre ligas, clubes y su plantilla.Dashboard Interactivo: Panel principal con acceso directo mediante tarjetas (tiles) hacia los módulos principales del sistema.Seguridad Aplicada: Exclusión de credenciales sensibles (DFConnId.ini) del control de versiones público y limpieza de pistas de acceso en la vista de autenticación.🏗️ Arquitectura del ProyectoLa estructura del repositorio está organizada siguiendo las mejores prácticas de un entorno DataFlex 25.0, versionando únicamente los recursos necesarios para el despliegue y desarrollo colaborativo:FutbolWebApp/

cd FutbolWebApp
Preparar la Base de Datos:Ejecuta el script SQL del proyecto en tu servidor MySQL para crear el esquema futbol y sus tablas.Verifica que tu origen de datos ODBC (DSN=Futbol) apunte correctamente a dicho esquema.Configurar las credenciales de conexión (DFConnId.ini):🔒 Por motivos de seguridad en repositorios públicos, el archivo Data/DFConnId.ini está excluido mediante .gitignore.Crea manualmente el archivo Data/DFConnId.ini con la siguiente estructura (o reconecta la base de datos desde el asistente de DataFlex Studio):[connection1]
id=Futbol
driver=ODBC_DRV
connection=DSN=Futbol
UID=<tu_usuario_mysql>
DFPWD250=<tu_contraseña_cifrada_por_dataflex>
Compilar y Ejecutar:Abre el archivo FutbolWebApp.sws en DataFlex Studio 25.0.Presiona F5 (Compile & Run) para generar Programs/WebApp.exe y lanzar la aplicación en http://localhost/FutbolMobWebApp/Index.html.🔀 Flujo de Trabajo (Gitflow)El desarrollo del proyecto se ha gestionado estrictamente bajo la metodología Gitflow, manteniendo un historial limpio y modularizado por cada funcionalidad solicitada:main     ●─────────────────────────────────────────────────────────● (Release Sprint 1)
